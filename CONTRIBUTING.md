# Contributing to Fractal

Thank you for considering a contribution to Fractal. Contributions are vital for building a more private and empowered distributed computing future.

## Code of Conduct

All participation in this project is governed by the [Fractal Code of Conduct](CODE_OF_CONDUCT.md). Participants are expected to uphold this code in all interactions.

## Contribution Channels

### Bug Reports
Reporting bugs helps maintain the reliability of the system.
*   **Use clear and descriptive titles** to identify the problem.
*   **Describe exact reproduction steps** to help others isolate the issue.
*   **Specify expected vs. actual behavior** with technical detail.
*   **Attach screenshots or logs** where applicable.

### Feature Suggestions
Enhancement suggestions are encouraged to evolve the system's capabilities.
*   **Provide a clear rationale** for how the feature benefits the user or the architecture.
*   **Outline proposed changes** in as much detail as possible.
*   **Explain the intended impact** on resource management or edge performance.

### First-Time Contributions
The `beginner` and `help-wanted` labels are used to identify tasks suitable for those new to the codebase. These often involve:
*   Improving documentation clarity.
*   Adding unit tests for core modules.
*   Refining UI telemetry visualizations.

## Pull Request Process

To submit a pull request:

1.  Fork the repository and create a branch from `main`.
2.  Maintain architectural consistency by following the MVVM pattern.
3.  Include tests for any logic changes.
4.  Update documentation for API or configuration modifications.
5.  Ensure all Gradle build checks pass locally.
6.  Submit the PR for review.

## Styleguides

### Kotlin Style
Adherence to the [official Kotlin style guide](https://kotlinlang.org/docs/coding-conventions.html) is required to maintain code readability.

### Commit Standards
*   Use the present tense ("Add feature", not "Added feature").
*   Use the imperative mood ("Fix bug", not "Fixed bug").
*   Reference related issues in the commit body.
